FAQ

Questions are generated live from Wikidata, so there is no fixed list. A question only runs if it has 50+ valid answers and enough well-known ones to be fair. Rarity comes from how widely known each answer is (Wikipedia language editions). Answers not in the listed pool are checked live. Wrong answers can be retried until the timer runs out. The daily dive uses a date seed; for identical questions for everyone, host a pre-built pack (see CFG.PACK_URL).

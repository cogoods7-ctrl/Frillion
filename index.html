FAQ

Questions are generated from Wikidata data packs that rebuild automatically, so there is no fixed list. A question only runs if it has 50+ valid answers and enough well-known ones to be fair. Rarity comes from how widely known each answer is (Wikipedia language editions). Answers not in the listed pool are checked live. Questions default to Easy (the best answer must be widely known and 25+ answers well-known); the daily dive is always Easy. Spelling correction is strict: one typo, a single unambiguous match, and never when what you typed is a real thing itself. Wrong answers can be retried until the timer runs out. The daily dive uses a date seed; for identical questions for everyone, host a pre-built pack (see CFG.PACK_URL).
